TASK LIFECYCLE:

  1. Job received from control plane with 'operation' field
     ↓
  2. TaskRegistry.get_task(operation) → finds Task implementation
     ↓
  3. Task.validate(context) → validates can execute
     ↓
  4. Task.execute(context) → performs work, returns TaskResult
     ↓
  5. Task.cleanup(context) → cleanup (always runs)
     ↓
  6. Result uploaded to control plane and S3


TASK ROUTING:

  Job {operation: "plan"} → TaskRegistry → TerraformPlanTask.execute()
  Job {operation: "apply"} → TaskRegistry → TerraformApplyTask.execute()
  Job {operation: "custom"} → TaskRegistry → CustomTask.execute()

CREATE A CUSTOM TASK:

  from task import Task, TaskContext, TaskResult, TaskStatus

  class MyCustomTask(Task):
      def get_type(self) -> str:
          return "my_operation"
      
      def execute(self, context: TaskContext) -> TaskResult:
          # Your logic here
          return TaskResult(
              status=TaskStatus.SUCCESS,
              output="Done!"
          )


REGISTER THE TASK:

  # In runner/loops.py → _register_tasks()
  self.task_registry.register(MyCustomTask())


CREATE A JOB:

  curl -X POST http://localhost:5000/api/jobs \
    -H "Content-Type: application/json" \
    -d '{
      "agent_id": "runner-001",
      "repo_url": "https://github.com/user/repo",
      "operation": "my_operation",    ← Task type string
      "env_vars": {},
      "metadata": {}
    }'

TASK BASE CLASS:

  class Task(ABC):
      @abstractmethod
      def get_type(self) -> str
          # Return task type string for routing
      
      @abstractmethod  
      def execute(self, context: TaskContext) -> TaskResult
          # Main execution logic
      
      def validate(self, context: TaskContext) -> bool
          # Pre-execution validation (optional)
      
      def cleanup(self, context: TaskContext)
          # Post-execution cleanup (optional)
      
      def can_retry(self, error: Exception) -> bool
          # Retry logic (optional)
      
      def get_timeout(self) -> int
          # Execution timeout in seconds (optional)


TASKCONTEXT:

  @dataclass
  class TaskContext:
      job_id: str                         # Job identifier
      task_type: str                      # Task type string
      config: Dict[str, Any]              # Job configuration
      runner_id: str                      # Runner identifier
      workdir: str                        # Working directory
      env_vars: Optional[Dict[str, str]]  # Environment variables
      metadata: Optional[Dict[str, Any]]  # Additional metadata


TASKRESULT:

  @dataclass
  class TaskResult:
      status: TaskStatus                  # SUCCESS, FAILED, CANCELLED
      output: str                         # Output text
      error: Optional[str]                # Error message
      artifacts: Optional[Dict[str, str]] # Generated file paths
      metadata: Optional[Dict[str, Any]]  # Additional metadata

  ❌ Hard to add new operations
  ❌ No clear separation of concerns
  ❌ Difficult to test individual operations
  ❌ Tight coupling

  ✅ Easy to add new task types
  ✅ Clear separation of concerns
  ✅ Each task is independently testable
  ✅ Loose coupling via registry
  ✅ Extensible plugin architecture
  ✅ Standardized lifecycle
  ✅ Comprehensive documentation
